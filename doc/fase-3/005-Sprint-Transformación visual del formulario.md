Transformación visual del formulario

Este es el sprint donde el módulo empieza a sentirse premium.

Objetivo

Cambiar el formulario desde una card simple a un formulario visual por secciones.

Secciones sugeridas

1. Información principal
   - Nombre
   - Categoría
   - Tipo de ejercicio
   - Dificultad

2. Clasificación deportiva
   - Músculo principal
   - Músculos secundarios
   - Patrón de movimiento
   - Equipamiento
   - Entorno

3. Prescripción sugerida
   - Series por defecto
   - Repeticiones por defecto
   - Tiempo sugerido
   - Descanso sugerido

4. Referencias
   - Video URL
   - Link de referencia
   - Descripción
   - Instrucciones paso a paso

5. Tags visuales
   - Gym
   - Mancuernas
   - Piernas
   - Empuje
   - Core
   - Calistenia
     Iconos
