\# CoachBoard



SaaS para gestión de entrenadores personales y sus atletas.



\## Estructura



\- `src/` → Backend ASP.NET 8 (API + EF Core)

\- `tests/` → Tests automatizados (.NET xUnit)

\- `frontend/` → Frontend React (se agrega en Módulo 3)

\- `docs/` → Documentación técnica y funcional
